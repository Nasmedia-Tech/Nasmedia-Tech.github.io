# NAP MX — kt nasmedia

kt nasmedia가 운영하는 모바일 광고 미디에이션 플랫폼 NAP MX의 제품 소개 페이지입니다 ([napmx.github.io](https://napmx.github.io/) 도메인으로도 접속 가능).

- **NAP MX SDK** (Android / iOS) — 배너, 전면, 네이티브, 리워드 동영상 등 다양한 광고 포맷과 Google, Kakao AdFit, Pangle, AppLovin, Unity Ads 등 주요 네트워크 미디에이션을 지원하는 SDK
- **NAP Tracking SDK** (Android / iOS) — 앱 내 사용자 행동 이벤트를 수집·분석하는 SDK
- **AdRevenue Lab**, **바이오리듬 with Buddy** — 위 SDK를 실제로 탑재해 운영 중인 서비스 앱 (Android · iOS)

SDK 연동 가이드는 [napmx.github.io](https://napmx.github.io/)에서 확인하세요. 이 저장소는 랜딩 페이지(`index.html`)와 서비스 앱들의 개인정보 처리방침/지원 페이지(`ad-revenue-simulator/`, `biorhythm/`)만 포함합니다.
