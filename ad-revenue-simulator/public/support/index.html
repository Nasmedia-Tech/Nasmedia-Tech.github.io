계산·목표·분석·시나리오·광고·공유 기능을 안전하게 사용하는 방법과 문제 해결 순서를 안내합니다.

앱 버전 1.0.7 · Android/iOS · 최종 업데이트 2026년 9월 19일

예상치 계산

입력한 가정에 따른 시뮬레이션이며 수익을 보장하지 않습니다.

로컬 저장

계산값과 시나리오는 기기에서 직접 초기화할 수 있습니다.

광고 선택권

리워드 광고는 선택 사항이며 핵심 기능을 잠그지 않습니다.

빠른 시작

  1. 계산 탭에서 MAU·DAU, OS 비중과 광고 조건을 입력합니다.
  2. 목표 탭에서 목표 수익과 필요한 조건을 확인합니다.
  3. 분석 탭에서 순수익, 손익분기점, 리워드 수익성과 민감도를 살펴봅니다.
  4. 시나리오 탭에서 현재 조건을 저장·비교하고, 더보기에서 설정·도움말·데이터 관리를 엽니다.
중요: 결과는 사용자가 입력한 가정에 기반한 참고용 예상치입니다. 실제 광고 수요, 계절성, 무효 트래픽, 매체 품질과 정책에 따라 정산 결과가 달라질 수 있습니다.

자주 묻는 질문

저장한 데이터는 어떻게 삭제하나요?

더보기 → 설정·개인정보·데이터 관리 → 저장 데이터 초기화를 선택합니다. 개별 항목은 시나리오 탭에서도 삭제할 수 있습니다. 앱 삭제 시 현재 기기의 앱 데이터는 제거되지만 운영체제 백업에 남은 사본이 복원될 수 있습니다. 공유한 파일은 수신 앱에서 따로 삭제해야 합니다.

입력값이 서버나 광고 사업자에게 전송되나요?

MAU·DAU·eCPM, 시나리오 이름·메모 등 계산 데이터는 기기 안에 저장되고 회사 서버나 광고 요청에 포함되지 않습니다. 다만 nap mx 광고의 제공·측정·빈도 제한·부정 이용 방지를 위해 기기·네트워크 정보, 광고 식별자와 광고 이용 이벤트가 처리될 수 있습니다. 자세한 내용은 개인정보 처리방침을 확인하세요.

업데이트 확인에서 어떤 정보가 전송되나요?

Android는 Google Play 인앱 업데이트 기능을 사용합니다. Google 공식 문서에 따르면 기기 메타데이터, 앱 버전, 설치된 모듈·애셋 목록이 업데이트 제공을 위해 처리됩니다. iOS는 설정 화면을 열 때 Apple에 앱 Bundle ID와 국가 코드(kr)로 조회하며, 현재 버전과의 비교는 기기에서 수행합니다. 어느 플랫폼도 회사의 별도 업데이트 서버로 계산 데이터를 보내지 않습니다.

광고가 보이지 않거나 로드에 실패합니다.

광고 재고가 없는 no-fill, 일시적인 네트워크 상태, 광고 차단 설정 또는 테스트 환경 때문에 표시되지 않을 수 있습니다. 네트워크 연결을 확인한 뒤 잠시 후 다시 시도하세요. 광고가 없어도 계산·저장·공유 기능은 계속 사용할 수 있습니다.

30분 광고 숨김은 어떻게 동작하나요?

더보기 → 설정·개인정보·데이터 관리 → 30분 광고 숨김에서 리워드 동영상을 끝까지 시청해 보상이 확인되면 해당 기기에서 30분 동안 앱 광고를 숨깁니다. 로드 실패·중도 종료 시에는 시간이 부여되지 않습니다. 리워드 시청 여부와 관계없이 핵심 계산 기능은 동일합니다.

CSV 내보내기 전에 전면 광고가 나타났습니다.

광고 숨김 상태가 아닐 때 앱 세션당 최대 한 번 전면 광고가 표시될 수 있습니다. 광고가 닫히거나 로드되지 않으면 운영체제 공유 화면으로 이어져야 합니다. 공유할 앱을 사용자가 직접 선택하며, 내보내기 전 시나리오 이름·메모에 개인정보나 회사 기밀이 없는지 확인하세요.

iOS 추적 허용을 거부해도 사용할 수 있나요?

예. ATT를 거부해도 계산·저장·공유·리워드 기능은 제한되지 않습니다. 광고는 제한된 형태로 계속 표시될 수 있습니다. 권한은 iOS 설정의 개인정보 보호 및 보안 → 추적에서 바꿀 수 있습니다.

Android 광고 맞춤설정을 바꾸려면?

Android 설정의 개인정보 보호 또는 Google 광고 메뉴에서 광고 ID 삭제·재설정과 광고 개인정보 선택을 관리할 수 있습니다. 메뉴 이름과 위치는 제조사·OS 버전에 따라 다를 수 있습니다.

큰 글자, 화면 읽기 또는 태블릿에서 문제가 있습니다.

기기 모델, OS 버전, 글자 크기, 화면 방향, 문제가 난 화면과 재현 순서를 알려 주세요. 스크린샷을 보낼 때는 알림·계정명·시나리오 메모 등 개인정보나 회사 기밀을 가려 주세요.

내 NAP MX 실적을 어떻게 가져오나요?

분석 → NAP MX에서 업데이트에서 본인의 Report API Key와 조회 기간을 입력하고 연결 테스트를 실행하세요. 조회 결과는 바로 저장되지 않고 미리보기로 표시됩니다. 기존 직접 입력·CSV 데이터와 충돌하면 현재 값을 유지할지 NAP MX 값으로 바꿀지 선택한 뒤 가져옵니다. 앱은 NAP MX에 없는 DAU·운영비 등의 값을 직접 보완할 수 있습니다.

NAP MX API Key는 어디에 저장되나요?

Android에서는 Keystore로 암호화한 백업 제외 저장소, iOS에서는 이 기기 전용 Keychain에 저장하며 회사 서버로 보내지 않습니다. 저장 후에는 전체 키를 다시 표시하지 않습니다. 연결 해제 시 키를 삭제하고 가져온 실적은 기본적으로 유지합니다. 문의·스크린샷·로그에 API Key를 보내지 마세요.
